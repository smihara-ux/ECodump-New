# ECO DUMP 施工側ナビゲーション改善の公開確認

2026-10-09。ユーザーによる再確認後の origin/main プッシュの承認に基づく変更です。

## 反映する修正

- 現場・搬出管理を統合し、既存23現場を横幅のある枠で縦に表示。
- 運行管理の地図・一覧を本文幅に配置。半段階ズーム、意図しないホイール拡大停止、本文内の拡張とEsc復帰。
- 労務安全を会社・現場ごとの一つの書類画面へ整理。6カテゴリの固有チェック項目、ID、版、コメント、履歴は保持。
- 基本台帳にドライバー検索を集約。会社4項目の内側メニューと編集・下書きを保持。
- 現場・協力会社・参加情報・書類に同じ会社IDと現場IDを使用。別現場への参加追加は既存参加・書類を移動しない。
- 関連画面、再読み込み、戻る／進むで対象と検索・開閉・スクロールを復元。
- 公開用ビルドで見つかった協力会社表への旧8列グリッドの干渉を修正。PCは5列の表、狭い本文は内容に応じて伸びるカード。
