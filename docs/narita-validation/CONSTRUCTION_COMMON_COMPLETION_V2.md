# 施工側・共通API/DB 実装確認（2026-09-25）

## 環境区分

- 確認済み: ローカルUI、隔離PostgreSQL、検証用認証、API保存・再取得・再ログイン、権限拒否。
- 未実施: 正式3者連携受入試験、実機試験、DGXステージング、本番公開、実利用者通知。

## 分類

| 領域 | 判定 | 内容 |
|---|---|---|
| 既存ナビゲーション、スケジュール、運行ダッシュボード、帳票 | 既存を維持 | 既存ルートと折りたたみを維持。上部3ボタンと現在地表示を継続 |
| 担当現場 | DB接続済み | A/B工区だけをサーバー担当範囲で取得。編集は版・理由・履歴・冪等キー付き |
| 直接予約 | DB接続済み | 申請と受入承認を分離。変更承認待ち・拒否・取消を共通状態化 |
| 複数便・外部運送 | DB接続済み | 1予約複数便、便別数量・時刻、委託許可ペア、重複検出、代車・代走、旧担当拒否 |
| 運行報告・例外 | DB接続済み | 到着・出発・受入到着・荷下ろし、遅延・未着・受入不可等を別記録 |
| 原票・受入実績 | DB接続済み | 便ID単位、予定/報告/受入確定を分離、差異理由、原票履歴、権限内取得 |
| 受入条件 | DB接続済み（一部仕様未確定） | 営業日・時間・土質・単位・日上限・理由履歴。空きは暫定値と明示 |
| GPS・ETC・OCR・Push | 未接続 | 接続済みとは表示しない。ETC推定と請求確定を混同しない |
