## 外部情報が揃い次第、実環境で行う項目

1. Supabase Project URL と publishable key を設定
2. `supabase/schema.sql` を対象プロジェクトへ適用
3. Authユーザー、所属組織、初期現場データを登録
4. RLSの実ユーザー間分離テスト
5. 運行予定・車両位置の画面接続とRealtime疎通確認
6. 本番ドメイン、監視、バックアップ、障害時運用を設定

## 自動検証

- `npm run test:ui`: 34件
- `npm run test:db`: 4件
- `npm run test:sites`: 4件
- `npm run db:check`: 公開環境変数への秘密鍵混入検査
- `npm run build`: 本番ビルドとSites配布物生成

## セキュリティ境界

- service role / secret key はフロントエンドへ配置しない
- ブラウザからのデータアクセスはRLSを必須とする
- 大型車経路は候補表示とし、実運行前に道路管理者・警察・許可経路の最新情報を確認する
